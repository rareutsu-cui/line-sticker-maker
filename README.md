# スタンプメーカー

Chromeの拡張アイコンから編集画面をタブで開く、Manifest V3の拡張機能です。

## Chrome / Chromiumへの読み込み

1. アドレス欄に `chrome://extensions` を入力します。
2. 右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、このリポジトリのフォルダを選びます。
4. ツールバーの拡張機能メニューで「スタンプメーカー」を固定し、アイコンを押します。

更新後は `chrome://extensions` の「スタンプメーカー」の再読み込みボタンを押し、開いている編集タブも再読み込みします。再読み込みの前に必要な画像を書き出してください。

## 使い方

バージョン2.0.0。画像を追加し、位置・拡大率・回転・背景の透過・文字を調整します。白紙へのペン描き、消しゴム、なぞって切り抜きにも対応します。「このスタンプをPNG保存」または「全部ZIPで保存」で書き出せます。

画像と編集状態はタブを開いている間のメモリ上に保持します。閉じたり再読み込みすると消えるため、作業後は書き出してください。画像処理とZIP生成は端末内で実行します。

## Web / PWA版

Webサーバーから `index.html` を開くと、同じ編集画面を使用できます。PWAの設定は `manifest.webmanifest`、Web版のオフラインキャッシュは `sw.js` です。

## 同梱ライブラリ

JSZip 3.10.1を `vendor/jszip.min.js` に同梱しています。取得元は公式npmパッケージ `jszip@3.10.1`、ライセンスは `vendor/JSZip-LICENSE.markdown` に含めています。
